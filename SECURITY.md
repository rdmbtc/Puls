# Security Policy

## Supported Versions

Currently, the `main` branch of this repository receives security updates. 

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Puls and our users' funds and data very seriously.

If you discover a security vulnerability within Puls, please do NOT report it by opening a public GitHub issue. 

Instead, please send an e-mail to our security team or reach out directly to the maintainers. We will try to address the issue as quickly as possible. 

Once the report has been received, we will:
1. Verify the vulnerability.
2. Develop a patch.
3. Coordinate a release that fixes the issue.
4. Issue a public security advisory, giving credit to the reporter.
