How to install the APK

1

Download the APK above on your Android phone (Android 8.0+).

2

Tap the file. If prompted, allow installs from this source (Settings → Install unknown apps) — standard for direct/beta APKs.

3

Open Puls, sign in with Google, and your gasless Circle wallet is created instantly. Grab testnet USDC from the in-app prompt and start swiping.
