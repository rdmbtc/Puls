How to install the APK

01

Download the APK

Grab the file above on your Android phone — you need Android 8.0+ and about 70 MB of space.

02

Allow the install

Tap the file. If prompted, allow installs from this source under Settings → Install unknown apps — standard for direct beta APKs.

Sign in and swipe

Open Puls, sign in with Google, and your gasless Circle wallet is created instantly. Grab testnet USDC from the in-app prompt and start swiping.
